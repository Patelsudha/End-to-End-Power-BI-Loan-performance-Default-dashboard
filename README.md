# Loan Default & Risk Analysis — Power BI Dashboard

A multi-page Power BI dashboard analyzing loan default patterns, applicant demographics, and financial risk metrics across a lending portfolio (2013–2018).

## 📊 Overview

This project explores loan performance and default behavior using key dimensions such as employment type, credit score, age group, marital status, education, and income bracket. It is built as a three-page interactive Power BI report.

## 📁 Dashboard Pages

### 1. Loan Default & Overview
High-level view of loan volume and default trends:
- Loan amount by purpose (Home, Business, Education, Auto, Other)
- Average income and default rate by employment type
- Average loan amount by age group
- Default rate (%) trend by year (2013–2018)

### 2. Applicant Demographics & Financial Profile
Deeper look at who is borrowing and their risk profile:
- Median loan amount by credit score category
- Average loan amount (high credit) by age group and marital status
- Total loan amount by credit score bins (adults segment)
- Mortgage/dependents breakdown for the middle-age segment
- Number of loans by education type

### 3. Financial Risk Metrics
Year-over-year risk and volume trends:
- YoY loan amount change by year
- YoY default loans change by year
- YTD loan amount by credit score bin and marital status
- Loan amount by income bracket and employment type

## 🧩 Key Metrics Tracked

| Metric | Description |
|---|---|
| Default Rate (%) | Share of loans in default, by year and employment type |
| Loan Amount | Total/average/median loan disbursed, sliced by multiple dimensions |
| YoY Change | Year-over-year percentage change in loan amount and default counts |
| Credit Score Bins | Very Low, Low, Medium, High segmentation of applicants |
| Income Bracket | Low, Medium, High income segmentation |

## 📌 Insights (Sample)

- Default rates are highest among unemployed applicants and trend slightly upward over the observed period.
- Loan amounts remain fairly consistent across purposes, with a slight lean toward Auto and Education loans.
- High-income borrowers account for the largest share of total loan volume.
- YoY default loan changes show volatility, with notable dips in 2016–2017 followed by a rebound.
